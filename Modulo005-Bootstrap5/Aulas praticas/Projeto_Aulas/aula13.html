Aula 13- Form-Control no Bootstrap

Nesta aula, praticamos a criação de formulários com Bootstrap, usando classes como form-label, form-control, btn, form-control-sm, form-control-lg, readonly, disabled, form-control-plaintext, visually-hidden e form-control-color.

1. Formulário sem classes do Bootstrap

O Bootstrap não aplica o visual automaticamente em todos os campos apenas por estar importado no projeto. Para que os elementos recebam o estilo do framework, precisamos usar as classes corretas.

No exemplo abaixo, o formulário funciona normalmente, mas os campos aparecem com o estilo padrão do navegador.

2. Formulário com form-label e form-control

A classe form-label estiliza o texto do campo, enquanto a classe form-control aplica o visual padrão do Bootstrap nos inputs.

Com essas classes, os campos ganham largura adequada, espaçamento interno, bordas padronizadas e efeito visual ao receber foco.

3. Botões com btn, btn-primary e px-5

Para estilizar botões no Bootstrap, usamos a classe base btn junto com uma classe de cor, como btn-primary.

A classe px-5 aumenta o espaçamento interno horizontal do botão, deixando-o mais largo.

4. Tamanhos dos campos com form-control-sm e form-control-lg

O Bootstrap permite alterar o tamanho dos campos usando classes específicas. A classe form-control-sm deixa o campo menor, enquanto form-control-lg deixa o campo maior.

5. Campos disabled e readonly

O atributo disabled deixa o campo desabilitado. O usuário não consegue editar o conteúdo e, normalmente, esse valor não é enviado junto com o formulário.

O atributo readonly também impede a edição, mas mantém o campo com comportamento mais próximo de um campo comum.

6. Campo com form-control-plaintext

A classe form-control-plaintext exibe o valor como texto simples, sem a aparência tradicional de um input.

Esse recurso é útil quando queremos mostrar uma informação fixa dentro de uma estrutura de formulário.

7. Label escondido com visually-hidden

A classe visually-hidden esconde o elemento visualmente, mas mantém a informação disponível para leitores de tela.

Isso é importante para acessibilidade, principalmente quando usamos campos com placeholder e não queremos exibir o label na tela.

8. Campo para carregar ficheiro

Para trabalhar com envio de arquivos, usamos o campo type="file".

Quando um formulário envia arquivos, é comum usar também o atributo enctype="multipart/form-data" na tag form.

9. Campo de cor com form-control-color

O campo type="color" permite selecionar uma cor. No Bootstrap, podemos usar a classe form-control-color para deixar esse campo com uma aparência mais adequada.

10. Campo de observações com textarea

O elemento textarea é usado para textos maiores, como mensagens, descrições e observações.

Assim como os inputs, ele também pode receber a classe form-control.

11. Exemplo prático completo

Neste exemplo, reunimos vários recursos estudados na aula: campos de texto, senha, upload de arquivo, seletor de cor, textarea e botão com Bootstrap.

Resumo da aula

  • O Bootstrap não aplica o estilo automaticamente em todos os campos.
  • A classe form-label estiliza os labels dos formulários.
  • A classe form-control aplica o visual padrão nos inputs.
  • As classes form-control-sm e form-control-lg alteram o tamanho dos campos.
  • A classe btn é a base dos botões no Bootstrap.
  • A classe btn-primary aplica a cor principal do Bootstrap no botão.
  • O atributo disabled bloqueia o campo.
  • O atributo readonly impede edição, mas mantém o campo legível.
  • A classe form-control-plaintext exibe o campo como texto simples.
  • A classe visually-hidden melhora a acessibilidade escondendo visualmente o label.
  • A classe form-control-color melhora a aparência do campo de seleção de cor.
