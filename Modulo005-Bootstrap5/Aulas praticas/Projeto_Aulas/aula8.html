Aula 8 - Margin e Padding no Bootstrap

Nesta aula, praticamos as classes utilitárias de espaçamento do Bootstrap, entendendo a diferença entre espaço externo e espaço interno.

Exemplo com margin

A margin cria espaço do lado de fora do elemento. No exemplo abaixo, usamos a classe mb-5 para aplicar uma margem inferior.

Este bloco possui margin-bottom com mb-5

Este bloco ficou mais afastado porque o bloco amarelo acima recebeu uma margem inferior.

Exemplo com padding

O padding cria espaço dentro do elemento, afastando o conteúdo das bordas internas.

Este bloco possui padding com p-5

Perceba que o texto não fica grudado nas bordas do bloco azul.

Comparação prática

Margin

Este bloco tem margin-bottom com mb-4.

A margin afastou este bloco do elemento acima.

Padding

Este bloco tem padding interno com p-4.

O padding aumenta o espaço interno entre o conteúdo e as bordas.

Classes estudadas nesta aula

  • m: margin em todos os lados
  • mt: margin-top
  • mb: margin-bottom
  • mx: margin no eixo horizontal
  • my: margin no eixo vertical
  • p: padding em todos os lados
  • pt: padding-top
  • pb: padding-bottom
  • px: padding no eixo horizontal
  • py: padding no eixo vertical
