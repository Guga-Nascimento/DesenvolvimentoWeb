Aula 10 - CSS Grid no Bootstrap e Tipografia

Nesta aula, estudamos a diferença entre o Grid tradicional do Bootstrap e o CSS Grid, além de praticar classes de tipografia, alinhamento de texto e listas.

1. CSS Grid no Bootstrap

O Grid tradicional do Bootstrap, que usamos com container, row e col, é baseado em Flexbox.

Já o CSS Grid é um recurso próprio do CSS, usado para criar layouts em formato de grade com linhas e colunas.

Bootstrap Grid: usa Flexbox por padrão.

CSS Grid: é um modelo de layout nativo do CSS.

O Bootstrap também possui uma opção relacionada ao CSS Grid, mas ela pode depender de configuração e recompilação com SASS. Por isso, neste momento, seguimos usando o modelo tradicional do Bootstrap.

2. Tipografia no Bootstrap

A tipografia está relacionada à forma como os textos aparecem na página: títulos, parágrafos, tamanhos, pesos, alinhamentos e listas.

O Bootstrap já aplica uma aparência padrão para as tags de título do HTML.

Resumo da aula

  • O Grid tradicional do Bootstrap é baseado em Flexbox.
  • CSS Grid é um modelo de layout próprio do CSS.
  • O Bootstrap permite aplicar aparência de títulos em outros elementos.
  • As classes display criam títulos maiores e mais destacados.
  • As classes text-start, text-center e text-end controlam alinhamento horizontal.
  • As classes list-unstyled e list-inline alteram a apresentação das listas.
