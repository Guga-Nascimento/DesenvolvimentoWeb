Aula 14 - Select e Range no Bootstrap

Nesta primeira parte da aula, praticamos o uso de campos select e range com Bootstrap, aplicando classes como form-select, form-select-sm, form-select-lg e form-range.

1. Select sem classes do Bootstrap

O elemento select é usado para criar uma lista de opções. Sem as classes do Bootstrap, ele funciona normalmente, mas mantém a aparência padrão do navegador.

Neste primeiro exemplo, ainda não foi aplicada nenhuma classe visual do Bootstrap.

2. Select com form-select

A classe form-select aplica o estilo padrão do Bootstrap ao campo de seleção.

Com ela, o campo ganha largura adequada, espaçamento interno, borda padronizada e aparência mais alinhada ao restante dos formulários.

3. Tamanhos do select com form-select-sm e form-select-lg

Assim como acontece com os inputs, o Bootstrap também permite alterar o tamanho do campo select.

A classe form-select-sm deixa o campo menor, enquanto a classe form-select-lg deixa o campo maior.

4. Select múltiplo com multiple

O atributo multiple permite selecionar mais de uma opção dentro do mesmo campo select.

Em muitos navegadores, para selecionar várias opções, o usuário pode usar a tecla Ctrl ou Shift junto com o clique.

5. Select múltiplo com size

O atributo size define quantas opções aparecem visíveis ao mesmo tempo dentro do select.

No exemplo abaixo, usamos size="5", então o campo exibe cinco linhas de opções visíveis.

6. Select desabilitado com disabled

O atributo disabled bloqueia o campo, impedindo que o usuário altere a opção selecionada.

Esse recurso pode ser usado quando uma escolha depende de outra informação ou quando o campo deve ficar apenas como visualização.

7. Range sem classes do Bootstrap

O campo input type="range" cria uma barra deslizante para escolha de valores.

Sem a classe do Bootstrap, ele mantém a aparência padrão do navegador.

8. Range com form-range

A classe form-range aplica o visual do Bootstrap ao campo de intervalo.

Essa classe melhora a aparência da barra, mas não exibe o número escolhido automaticamente.

9. Range desabilitado

Assim como outros campos de formulário, o range também pode ser bloqueado com o atributo disabled.

Quando está desabilitado, o usuário não consegue mover o controle.

10. Range com min e max

Os atributos min e max definem o valor mínimo e o valor máximo permitidos no campo.

No exemplo abaixo, o valor pode variar de 0 até 100.

11. Range com step

O atributo step define de quanto em quanto o valor será alterado.

No exemplo abaixo, usamos step="10". Isso significa que o range avançará de 10 em 10.

12. Checkbox simples

O checkbox é usado quando o usuário pode marcar ou desmarcar uma opção.

Para estilizar esse tipo de campo no Bootstrap, usamos a estrutura com form-check, form-check-input e form-check-label.

13. Checkbox checked e disabled

O atributo checked faz com que a opção já venha marcada quando a página é carregada.

O atributo disabled bloqueia a opção, impedindo que o usuário altere seu estado.

14. Radio buttons

O radio button é usado quando o usuário deve escolher apenas uma opção dentro de um grupo.

Para que apenas uma opção seja marcada, todos os radios do mesmo grupo precisam ter o mesmo atributo name.

15. Opções inline

A classe form-check-inline coloca as opções lado a lado, em vez de deixar cada opção em uma linha.

Esse recurso pode ser usado tanto em checkboxes quanto em radio buttons.

16. Switches

O switch é uma variação visual do checkbox. Ele é muito usado para representar opções de ativar ou desativar algo.

Para criar um switch no Bootstrap, usamos form-check, form-switch, form-check-input e o atributo role="switch".

17. Switch inline e reverse

A classe form-check-inline deixa os switches lado a lado.

A classe form-check-reverse inverte a posição, colocando o texto antes do controle.

18. Input group com texto antes do campo

O input group permite juntar textos, símbolos, botões ou outros elementos ao campo de formulário.

A classe input-group cria o agrupamento, enquanto input-group-text estiliza o texto auxiliar.

Resumo da aula

  • A classe form-select aplica o visual do Bootstrap no campo select.
  • As classes form-select-sm e form-select-lg alteram o tamanho do select.
  • O atributo multiple permite selecionar mais de uma opção.
  • O atributo size define quantas opções aparecem visíveis no select.
  • A classe form-range aplica o visual do Bootstrap ao input type="range".
  • O Bootstrap não mostra o valor numérico do range automaticamente.
  • Os atributos min, max e step controlam o comportamento do range.
  • A estrutura form-check organiza checkboxes e radio buttons.
  • A classe form-check-input estiliza o campo de marcação.
  • A classe form-check-label estiliza o texto da opção.
  • O atributo checked deixa uma opção marcada por padrão.
  • O atributo disabled bloqueia a interação com o campo.
  • A classe form-check-inline coloca as opções lado a lado.
  • A classe form-switch transforma um checkbox em switch.
  • A classe form-check-reverse inverte a posição do controle e do texto.
  • A classe input-group agrupa campos com textos, símbolos ou outros elementos.
  • A classe input-group-text estiliza os elementos auxiliares do grupo.
