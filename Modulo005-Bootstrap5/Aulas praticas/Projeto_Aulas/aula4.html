Aula 4 - Alinhamento de Rows dentro de Cols

Nesta aula, vamos aprender como criar uma row dentro de uma col, formando um grid aninhado no Bootstrap.

O que esta aula ensina?

No Bootstrap, a estrutura básica do grid é: container → row → col.

Porém, em alguns layouts, precisamos dividir uma coluna em novas partes. Para isso, colocamos uma nova row dentro de uma col.

Esse recurso é chamado de grid aninhado e aparece bastante em layouts profissionais, como cards, dashboards, áreas de serviços e páginas de portfólio.

Exercício prático

A

B

C

Como o layout se comporta?

  • No celular, A, B e C ficam um abaixo do outro.
  • A partir de sm, ou seja, 576px, a coluna A ocupa metade da tela.
  • A outra metade da tela fica com uma segunda coluna, que contém B e C.
  • A partir de lg, ou seja, 992px, B e C ficam lado a lado dentro da coluna principal.

Resumo das classes usadas

  • container: centraliza o conteúdo e define uma largura máxima responsiva.
  • row: cria uma linha dentro do sistema de grid.
  • col-12: faz a coluna ocupar toda a largura disponível.
  • col-sm-6: a partir de 576px, faz a coluna ocupar metade da linha.
  • col-lg-6: a partir de 992px, faz a coluna ocupar metade da row interna.
  • g-3: adiciona espaçamento entre as colunas.
  • p-4: adiciona espaçamento interno.
  • border: adiciona borda ao elemento.
  • rounded: arredonda os cantos.
  • h-100: faz o bloco ocupar toda a altura disponível.
  • text-center: centraliza o texto.
