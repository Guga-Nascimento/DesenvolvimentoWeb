Aula 12 - Tabelas no Bootstrap

Nesta aula, praticamos a criação e formatação de tabelas usando as classes do Bootstrap. O foco foi entender como melhorar a apresentação de dados sem usar tabelas para montar layout.

1. Para que servem as tabelas no HTML?

As tabelas devem ser usadas para apresentar dados organizados em linhas e colunas. Antigamente, tabelas também eram usadas para montar layouts de páginas, mas isso é uma má prática.

Atualmente, para layout usamos recursos como Flexbox, CSS Grid e o próprio Grid do Bootstrap. Já as tabelas ficam reservadas para dados, relatórios, cadastros, comparações e listagens.

Uso correto: apresentar dados.

Uso incorreto: montar o layout visual da página.

2. Tabela HTML sem formatação do Bootstrap

Uma tabela HTML pura funciona normalmente, mas visualmente fica muito simples. O Bootstrap não estiliza totalmente a tabela sozinho. Para aplicar o estilo, precisamos usar a classe table.

15. Tabela responsiva com table-responsive

Quando uma tabela tem muitas colunas, ela pode estourar a largura da tela em celulares. Para evitar isso, colocamos a tabela dentro de uma div com a classe table-responsive.

Essa classe cria uma rolagem horizontal quando necessário, mantendo a página mais organizada em telas pequenas.

Resumo da aula

  • table: classe base para estilizar tabelas no Bootstrap.
  • table-primary, table-success, table-warning e outras: aplicam cores.
  • table-striped: cria linhas alternadas.
  • table-striped-columns: cria colunas alternadas.
  • table-hover: destaca linhas ao passar o mouse.
  • table-active: destaca uma linha ou célula específica.
  • table-bordered: adiciona bordas em toda a tabela.
  • table-borderless: remove as bordas da tabela.
  • border-primary: altera a cor das bordas.
  • table-sm: reduz o espaçamento interno das células.
  • table-dark: aplica visual escuro, muito usado no cabeçalho.
  • table-responsive: melhora a visualização de tabelas grandes em telas pequenas.
