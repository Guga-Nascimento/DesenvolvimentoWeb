Aula 5 - Column Offsets

Nesta aula, vamos aprender como deslocar colunas para a direita usando as classes de offset do Bootstrap.

O que são Column Offsets?

No Bootstrap, as classes de offset servem para criar um espaço vazio antes de uma coluna.

Esse deslocamento segue a mesma lógica do grid de 12 colunas. Por exemplo: se uma coluna ocupa 8 partes e recebe offset-2, ela será empurrada 2 partes para a direita.

Esse recurso é útil para centralizar blocos, criar espaçamentos laterais e posicionar elementos sem precisar escrever CSS personalizado.

Resumo das classes usadas

  • container: centraliza o conteúdo e define uma largura máxima responsiva.
  • row: cria uma linha dentro do sistema de grid.
  • col-12: faz a coluna ocupar 12 partes do grid no celular.
  • col-sm-8: faz a coluna ocupar 8 partes a partir de 576px.
  • offset-sm-2: empurra a coluna 2 partes para a direita a partir de 576px.
  • col-lg-4: faz a coluna ocupar 4 partes a partir de 992px.
  • offset-lg-4: empurra a coluna 4 partes para a direita a partir de 992px.
  • p-4: adiciona espaçamento interno.
  • border: adiciona borda ao bloco.
  • rounded: arredonda os cantos.
  • text-center: centraliza o texto.
