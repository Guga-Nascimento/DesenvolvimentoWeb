Aula 11 - Imagens Responsivas e Cores no Bootstrap

Nesta aula, praticamos o uso da classe img-fluid para tornar imagens responsivas e também fizemos uma breve introdução às cores padrão do Bootstrap.

1. Imagens responsivas com img-fluid

A classe img-fluid é usada para fazer com que a imagem respeite o tamanho disponível dentro do elemento onde ela está inserida.

Na prática, essa classe aplica uma largura máxima de 100% e mantém a altura automática, evitando que a imagem fique distorcida.

max-width: 100%; impede que a imagem ultrapasse a largura disponível.

height: auto; mantém a proporção original da imagem.

2. Exemplo com imagem pequena

A imagem pequena normalmente não causa tantos problemas no layout, pois já possui uma largura menor.

3. Exemplo com imagem grande responsiva

Quando usamos uma imagem muito grande, ela pode ultrapassar o espaço da página. Por isso, usamos img-fluid para limitar a imagem ao tamanho disponível.

Resumo da aula

  • A classe img-fluid torna imagens responsivas.
  • img-fluid evita que imagens grandes ultrapassem o espaço disponível.
  • Dentro do Grid, a imagem respeita o tamanho da coluna.
  • As classes bg-* aplicam cores de fundo.
  • As classes text-* aplicam cores no texto.
  • As cores padrão do Bootstrap são úteis, mas possuem uma paleta limitada.
