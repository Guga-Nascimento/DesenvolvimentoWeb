# 💻 Desenvolvimento Web

Repositório com minha trilha prática de estudos em desenvolvimento web, com foco na construção de projetos reais, organização de código e evolução contínua até aplicações completas.

## 🚀 Sobre o projeto

Este repositório reúne minha jornada de aprendizado em desenvolvimento web, passando pelos fundamentos de HTML, CSS e JavaScript até tecnologias utilizadas no mercado, como Bootstrap, PHP e MySQL.

O conteúdo está organizado por módulos, cada um focado em uma tecnologia ou etapa específica da construção de aplicações web.

A proposta é estudar de forma prática, criando exercícios, páginas, componentes e pequenos projetos para consolidar o aprendizado.

## 🧠 Tecnologias abordadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- PHP
- MySQL
- Git e GitHub

## 📚 Aprendizados recentes

Durante os estudos mais recentes, pratiquei a criação de layouts responsivos com Bootstrap, utilizando o sistema de grid para adaptar colunas em diferentes dispositivos.

Um exemplo trabalhado foi a criação de uma página onde:

- No smartphone, as colunas ocupam 12 unidades
- No tablet, as colunas se reorganizam em proporções diferentes
- No desktop, as colunas ficam distribuídas igualmente

Esse exercício ajudou a fixar melhor o conceito de responsividade e o funcionamento dos breakpoints do Bootstrap.
